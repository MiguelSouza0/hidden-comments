# Demonstração

Conteúdo fictício, para capturas de tela sem expor código real.

| Arquivo | O que é |
|---|---|
| `template.html` | Template Jinja com comentários em HTML, JS e CSS |
| `template_convertido.html` | O mesmo template depois da conversão da extensão |
| `navegador_antes.html` | O que o navegador recebe hoje: 6 comentários internos visíveis |
| `navegador_depois.html` | O que o navegador recebe após a conversão |

Abra os dois `navegador_*.html` no Chrome e compare em **Inspecionar → Elements**.
